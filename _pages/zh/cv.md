## 开源代码与数据集

- [**KnottedGraph**](https://github.com/HakanAkgn/KnottedGraph)：用于纽结图构建、可视化与分析的 Python 框架，支持可扩展的 Yamada 多项式计算。

- [**poly2graph**](https://github.com/sarinstein-yan/poly2graph)：从特征多项式与 Bloch 哈密顿量自动构建哈密顿量谱图的 Python 软件包。
- [**HSG-12M**](https://github.com/sarinstein-yan/HSG-12M)：基于 NetworkX 与 PyTorch Geometric 的 HSG-12M 空间多重图数据集下载、处理、子集提取与基准测试代码。
- [**HSG-12M (Data)**](https://doi.org/10.7910/DVN/PYDSSQ)：发布于 Harvard Dataverse 的空间多重图数据集，提取自非厄米晶体的能谱。
- [**ClusterAnalyzer**](https://github.com/HakanAkgn/ClusterAnalyzer)：用于分析二维元胞自动机团簇临界行为、自相似性与分形维数的 Python 库。
